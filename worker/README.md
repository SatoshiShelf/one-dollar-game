# Satoshi Shelf worker — secure BTC-gated delivery

This Cloudflare Worker verifies Bitcoin payments **server-side** and only then
serves the product file. The paid files are embedded into the Worker bundle at
deploy time and are **never** published in the public website repo.

## How it works

```
buyer pays BTC
   -> POST /verify  { productId, txid }
        worker fetches live BTC price, looks up the tx on mempool.space,
        checks a vout pays your address >= the product price,
        returns a 15-minute signed token (HMAC)
   -> GET  /download?token=...   -> the file (private, not on the public site)
```

## One-time setup

```bash
cd worker
npm install                 # installs wrangler
npx wrangler login          # opens browser, authorises Cloudflare (free account)

npx wrangler secret put DOWNLOAD_SECRET
# paste any long random string when prompted (e.g. from `openssl rand -hex 32`)
```

`BTC_ADDRESS` is set in `wrangler.toml`.

## Deploy

```bash
npm run deploy
```

You'll get a URL like:

```
https://satoshi-shelf.<your-subdomain>.workers.dev
```

**Paste that URL into `assets/products.js` as `workerUrl`**, commit, and push.
The store then uses secure delivery automatically. Leave it `""` to fall back to
public file links (not secure).

## Local dev

```bash
npm run dev     # builds embedded.js then runs a local worker
npm test        # unit tests
node integration.test.mjs   # end-to-end handler test
```

## Delivery links (MediaFire, etc.)

External delivery links live in `worker/deliveries.local.json` (**gitignored** —
never public). The worker returns the matching link only after a verified
payment, and the link is never exposed in the public website JS.

```json
{
  "playbook": "https://www.mediafire.com/file/..../file",
  "starter-kit": "https://...",
  "ai-toolkit": "https://..."
}
```

Change a link, then redeploy:

```bash
npm run deploy
```

If a product has no link here, `build.mjs` embeds the local file from
`products/` instead and the worker serves it directly.

## Notes

- `src/embedded.js` (the base64 of your product files) is generated by
  `build.mjs` and is **gitignored** — never commit it.
- Tokens expire after 15 minutes and are signed, so `/download` can't be called
  without a genuine payment.
- To stop one txid being shared by many buyers, add a KV namespace and record
  used txids in `/verify`. Ask if you want this added.
